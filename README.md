# Book Management System

A simple full-stack Book Management System built using React. 
The application allows users to add, view, update, and delete books.


# Features

- View all books
- Add a new book
- Edit existing books
- Delete books
- Responsive UI
- Full CRUD operations

  # Tech Stack

## Frontend
- React.js
- Vite
- Axios
- CSS

## Backend
- MockAPI / Node.js / Express (whichever you used)
